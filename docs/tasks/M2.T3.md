# M2.T3: Execute and attribute manual sweeps

Status: planned; no implementation in this change.

**Outcome:** Each manual full-balance drain keeps its own source transfers, fees and recovery
identity.

**Learn:** Chain execution order, full-balance accounting and submission versus settlement.

- Depends on: [M2.T1](M2.T1.md), [M2.T2](M2.T2.md).
- Primary journey ownership: J2.S4, J3.S4, J4.S1, J4.S2.
- Policy: D28, D33, D39, D121, D128, D139. Invariants: I1, I10, I11.
- Rough effort: 2–3 focused developer days, excluding external waits.
- Expected locations: packages/server/src/operations/manual.

## Checkpoint 1: Start one eligible SDK command

- [ ] Reviewed with Vinay; focused checks and remaining evidence recorded.

**Build:** Claim the address's one open manual command after safe minimum/maximum guards. Reuse
ensure_contract, then submit Base forwarding or bounded Arbitrum burning through M2.T1. Keep
sub-minimum balances waiting.

**Check:** Exercise J2.S4.c9/c15–c19 and J4.S1.c3–c5/J4.S2.c6–c7. A budget pause preserves the same
command and no rejected sweep charges USDC.

**Walk through:** Why must the contract repeat guards already checked by the server?

## Checkpoint 2: Attribute by the actual drain boundary

- [ ] Reviewed with Vinay; focused checks and remaining evidence recorded.

**Build:** Reconstruct memberships after the preceding successful USDC drain in chain order. Include
mid-workflow top-ups, exclude quoted funds and handle a previous recovery boundary. Connect each
command only to its verified execution.

**Check:** Execute a third-party sweep first, index its evidence last, and add funds between
preparation and execution. Generated orderings prove D121/I1/I10; recovery-owned transfers cannot
fund a later credit.

**Walk through:** Which sweep owns a deposit that arrived after the workflow began but before the
contract executed?

## Checkpoint 3: Recover A without losing an external drain B

- [ ] Reviewed with Vinay; focused checks and remaining evidence recorded.

**Build:** Keep A's command open across mint delay. Discover and settle B independently if another
caller drains later funds; do not start a competing SDK command. Track A's saved signed transaction
until its canonical outcome is known.

**Check:** Crash after A's burn, add funds, execute B externally and restart. Assert J6.S1.c14 and
J2.S4.c17/J4.S2.c15; each drain retains its own tag and memberships.

**Walk through:** Why does discovering B not prove that A's unknown transaction can be discarded?

**Out of scope:** Partial burns, sweep-fee changes to old addresses and recovery submission.

## Done and handoff

balance is claimed before M2.T5–M2.T7 verification and delivery.

**Keep as evidence:** Two-drain accounting with source identities, emitted gross/fee/net and the
separate submitting command.

Use exact criterion/invariant IDs in tests; see the shared protocol for naming,
merge checks and the checkpoint handoff. Do not start the next task automatically.
